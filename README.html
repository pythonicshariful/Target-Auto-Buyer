🔌 How to Connect Discord & Telegram

💬 Step-by-Step Discord Webhook Setup

  1. 1Open Discord: Open your Discord desktop app or web browser and go to your private server.
  2. 2Edit Channel: Hover over the text channel you want notifications in (e.g. #drop-alerts) and click the Edit Channel gear icon (⚙️). (Or open Server Settings → Integrations → Webhooks).
  3. 3Create Webhook: Click Integrations on the left, then click Webhooks → New Webhook.
  4. 4Copy URL: Name the bot (e.g., Target Auto Buyer), select the channel, and click Copy Webhook URL.
  5. 5Enable in Bot: On Target, open the bot HUD, expand 🔔 Alerts & Notifications, toggle Discord Webhook to ON, paste the URL, and click Test Discord Webhook.

✈️ Step-by-Step Telegram Bot Setup

  1. 1Open BotFather: In the Telegram search bar, search for @BotFather (ensure it has the official blue verification badge).
  2. 2Create New Bot: Send /newbot. Choose a friendly name (e.g., Target Alerts) and a username ending in bot (e.g., target_auto_drop_bot).
  3. 3Copy Bot Token: BotFather will give you an HTTP API Token (e.g., 7123456789:AAFlkJ389asdf89asdf23jkl_asdf). Copy it.
  4. 4Start Your Bot: Open the link to your bot (e.g., t.me/target_auto_drop_bot) and click Start. (Required: bots cannot message you first!).
  5. 5Find Chat ID:
    • Personal DMs: Search for @userinfobot or @RawDataBot on Telegram, send any message, and copy your numerical Id (e.g., 123456789).
    • Channels/Groups: Add the bot as an Administrator with "Post Messages" permission. Use your channel's public handle (e.g., @my_channel) or forward a message to @RawDataBot for the negative ID (e.g., -100123456789).
  6. 6Enable in Bot: In the bot HUD, expand 🔔 Alerts & Notifications, toggle Telegram Bot to ON, paste your Bot Token and Chat ID, and click Test Telegram Message.

🔊 Audio Chimes Guide

The bot includes built-in audio synthesizer alerts built using the Web Audio API:

  • Stock Detected: Ascending arpeggio (C5: 523Hz → E5: 659Hz → G5: 783Hz → C6: 1046Hz).
  • Cart Confirmed: Positive confirmation double chime (G5: 783Hz → C6: 1046Hz).
  • Order Confirmed: Celebratory victory fanfare arpeggio!
  • Error / Warning: Sawtooth dual alert tones.
Browser Audio Tip: Modern browsers require at least one user gesture on the webpage before audio output is permitted. Starting the bot or clicking the Test button automatically unlocks the audio context.

🚀 Core Features & Purchase Architecture

  • Dual-Mode Monitoring: Combines RedSky REST fulfillment API polling with live DOM MutationObservers to detect when Target clears out-of-stock flags.
  • Intelligent Cart Drawer Handling: Detects Target's slide-out drawer confirmation (Added to cart, View cart & check out) and auto-declines warranty/protection plan modals.
  • Rapid Single-Pass Checkout: Continuously evaluates checkout pages at 200ms intervals, fills CVV, and clicks Place Order once.
  • Duplicate Prevention: Prevents multiple clicks on the Place Order button and tracks order confirmation elements.
  • Floating Resizable HUD: Compact/Large panel sizes, minimizable to top bar, draggable header with remembered screen coordinates.
